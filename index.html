Sobre o projeto

Criação de interfaces digitais que combinam design, movimento e interatividade.

Beyond the Code é um projeto experimental de desenvolvimento frontend, feito para demonstrar diferentes possibilidades visuais e técnicas: tipografia cinética, narrativa guiada pelo scroll, campanhas interativas e componentes acessíveis.

Experimental · Frontend · Conteúdo 100% fictício

06 — Encerramento · Estudo de caso

Como foi construído.

Resumo técnico baseado no código e nos testes feitos durante o desenvolvimento. Não há métricas comerciais: este é um projeto experimental.

Objetivo

Reunir, em uma só página, técnicas de frontend que costumam ser vistas isoladas (tipografia cinética, scroll storytelling, transformação de layout e componentes acessíveis) e mantê-las coerentes sob uma única identidade visual.

Tecnologias

  • HTML · CSS · JavaScript
  • Vite 8
  • GSAP 3.15
  • ScrollTrigger
  • SplitText
  • Flip
  • Lenis 1.3
  • CSS 3D
  • Fonte variável
  • WAI-ARIA

Funcionalidades

  • Abertura com peso de fonte reagindo ao cursor.
  • Narrativa fixa em 4 capítulos controlada pela rolagem.
  • 3 campanhas conceito cuja composição se transforma ao escolher.
  • Estúdio de composição, microinterações e laboratório de movimento.
  • Carrossel, abas, modal, aviso e cartão 3D, com teclado.

Desafios e soluções

Âncora da narrativa pinada caía no fim do pin.
A âncora usa o início do pin e o menu tem gatilho próprio.
A rotação em CSS era anulada pelo Flip (rotate: none inline).
Cor e rotação foram para um pseudo-elemento, controlado por variável.
Texto em contorno mostrava linhas internas na fonte variável.
paint-order: stroke fill com preenchimento na cor do fundo.
Tipografia cinética tremia ao mudar o peso.
Largura fixa por letra, ~40 fps e pausa fora da tela.
Transformar a campanha sem tremer o texto.
Flip só nas formas; o texto sai e entra com SplitText.

Limitações e pendências

  • Movimento reduzido testado só por simulação; falta testar a preferência real do sistema.
  • Sem teste em toque físico, leitor de tela ou medição de desempenho em hardware modesto.
  • Sem fotografias: as imagens são composições em CSS e SVG.
  • Fontes via Google Fonts; offline usa fonte alternativa.
