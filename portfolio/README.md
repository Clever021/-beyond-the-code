# Materiais de portfólio — Beyond the Code

- `capturas/` — 19 capturas de tela do site em produção local (`npm run build` + `npm run preview`), geradas com o Edge em modo headless:
  - **Desktop 1440×900:** `01` a `15` (abertura, introdução, capacidades, narrativa em 3 pontos, 3 campanhas, laboratório, componentes, estudo de caso, desafios e autoria, encerramento).
  - **Mobile 375×812:** `20` a `23`.
- `DESAFIOS_TECNICOS.md` — três desafios técnicos explicados para quem está começando.

## Texto curto para apresentar o projeto

> Beyond the Code é um projeto experimental de frontend (HTML, CSS, JavaScript, Vite, GSAP e Lenis) que reúne tipografia cinética, scroll storytelling em 3D, campanhas interativas e componentes acessíveis. Feito com assistência de IA sob direção criativa humana. Conteúdo 100% demonstrativo.

## Gravação em vídeo

Não incluída: o ambiente de desenvolvimento não tinha ferramenta de gravação/conversão e nada foi instalado. Para gravar: abra `npm run preview` e use a Barra de Jogos do Windows (`Win + Alt + R`) por ~30 s, percorrendo as seções e escolhendo as 3 campanhas.
